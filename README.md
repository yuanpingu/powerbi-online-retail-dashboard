# E-commerce Sales Analytics Dashboard (Power BI)

## Overview

This project analyzes an online retail dataset using Microsoft Power BI.

The dashboard provides interactive insights into:

- Revenue performance
- Product Performance
- Customer behaviors
- Invoice cancellations
